declared dependencies and peer dependencies. Those packages are distributed
under the licenses identified by their own npm manifests; installation does not
relicense them or the DeepSeek Harness runtime.

The plugin's original source files are MIT-licensed. The desktop application at
the repository root remains GPL-3.0-only and is not part of this package. No
GPL-licensed desktop source file is included in the npm package.
