## 校验方法

从执行矩阵的DAG表读取ID/依赖，与每份Spec的 Blocked by 比较；DFS检查环；按必备标题/边界字段校验；解析 Markdown 相对链接并 Test-Path；提取测试命令路径区分现有与拟新增；Get-FileHash SHA256核对manifest；最后 git status --short / git diff --stat 检查变更范围。没有用“文件存在”冒充运行退出码。
