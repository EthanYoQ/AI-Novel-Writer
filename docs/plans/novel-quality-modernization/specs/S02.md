## 现行增量：规划范围、目标与作者恢复入口（2026-10-04）

本节规定现有界面的接线，不证明实现或验收完成。
内容采用及恢复由 [S06A](S06A.md#chapter-planning-recovery)拥有，模型容量由 [S07](S07.md#planning-budget-range)拥有。
本节取代原冻结规格中阻止这些必要接线的文件范围限制，不扩大其他资源的写入权限。

### 范围与目标设置

- 大纲和蓝图每次动作默认 5 章，可选 1–10 章。项目总章数可大于 10，界面不得自动遍历全书。
- 两类规划各有每章目标，分别默认 600，可设为 1–1000 的整数。1000 只限制设置值，完整输出超过它仍按 S06A 接受。
- 单位取决于项目写作语言。中文展示汉字量，其他语言沿用既有词数单位；不随界面语言改变。
- 沿用 GlobalConfig 的两个顶层本机偏好 `outlineTargetUnits`、`blueprintTargetUnits`。保存后重开恢复上次目标，不新增项目列或导出迁移。
- 不复用正文的 `wordsPerChapter`。目标只指导大纲主叙述或蓝图 keyEvents，不限制完整 JSON 与身份、关系元数据。
- 覆盖 ArchitectureConfirmDialog 的 WorldBuildingEditor、ArchFileViewer 两个调用者，以及 DirectoryConfigDialog。
- 确认时提交实际章范围与目标；主进程冻结后，界面改偏好不改变旧动作。Agent 的相同确认语义见 [S06D](S06D.md#agent-planning-scope)。
- 模型设置显示 S07 的实际有效输出值。新建和重置默认 65536，已验证能力更低时取小值；已有作者显式配置保留。

### 编辑、保存与继续

规划失败入口须打开可编辑的保留成果，接通编辑、零模型保存和缺章继续。
作者可保存完整连续前缀；没有完整章时，也能明确发起只针对缺章的新动作。
保存范围、旧运行撤权、来源冲突和重复确认均由 S06A 的主进程路径核验，不能只在界面隐藏按钮。
界面不得将旧失败、费用未知或本地停止显示为成功，也不能声称已经取消远端请求。

验收使用两个架构入口、目录入口及实际错误编辑器。
检查默认 5/600、可选 10/1000、11 章和 1001 目标的拒绝，以及超过目标的完整输出保留。
同时检查偏好重开、旧动作目标不变、保存后重开与缺章继续；受影响界面沿用现有浏览器和桌面验证，不另建全量视觉验收。

## 实施步骤

1. 实现 typed parser/formatter，区分 core/draft/manuscript/revision/review；保留角色只读投影，不映射成任意可写文件。
2. 逐项迁移 UI 打开/历史 tab/版本比较、workflow/Agent/footer smoke 消费点；旧 URI 仅经集中 legacy parser 读，序列化新状态只产生新 URI。
3. bridge expose、类型、IPC client 和 direct finalization/release smoke 一次接入主集成者；新接口缺失要正确报启动错，不偷偷 fallback 到旧写接口。
4. 扫描 CSS/localStorage/DOM 标识先登记；本片改活跃资源消费者，死代码和锁文件集中 S13 处理。

## 失败、回退与交付

保持集中 read-only legacy parser 到最终退出；入口接入失败不切换新写接口。列明测试改名对应，不能运行已删除路径而计通过。

必交：URI/bridge 消费者逐项覆盖表、新读写权限用例、一个共享接线请求/receipt；磁盘格式迁移不属本片。 另按通用合同交 base/dependency/final SHA、测试退出码/入口覆盖及 failed/blocked/not-run。代码检查、确定性、真实模型和桌面资格不能互相代替。
