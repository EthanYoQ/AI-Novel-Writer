## 实施步骤

1. 逐旧实体分配稳定 ID，保留旧 key、显示快照和原关联证据，迁移 effect 幂等；历史同名不能自动合并。
2. 实现 resolved/ambiguous/unresolved resolver，别名范围和版本明确；不可判定关联输出 proposal，不以第一个匹配填正式 ID。
3. 静态资料补来源和批准收据，保留已有动态 provenance；AI 生成后作者采用不抹掉模型来源。
4. 提供有限 name-only 兼容读/import adapter；规范写必须 ID。S09 未接入口不能绕 adapter 写事实。M02 在 M01 后串行登记。
