## 目标与非目标

一个主进程 owner 管物理请求、根预算、取消和可见成果持久化；用现有 facade 供分波入口消费，不建通用 scheduler。 不扩展到 DSH、真实小说改写或正式发布。

拟新增 `electron/services/generation-run-service.ts`、`electron/repositories/generation-run-repository.ts`、M01 function；`electron/repositories/recovery-candidate-repository.ts`、`src/services/generation/{generation-runtime,generation-harness}.ts`。共享 IPC/db/registry 只提交单一接线请求。

你不是唯一开发者；不改其他片/共享区，不回滚他人改动，不再开子代理。接线以本合同的单一共享请求交主集成者。

## 实施步骤

1. 实现 rootAction 幂等创建/lineage、原子 reserve/dispatch-marked/settle/unknown 与累计 active elapsed；重启不重置，输入/输出/reasoning 正确计量，不确定请求不自动当免费重发。
2. 规范 adapter delta/cumulative 输出；单 owner CAS 全文快照与 terminal flush，最大 durable revision 收据驱动 UI。新 attempt 分片，不猜 delta 重放去重、不跨模型拼稿。
3. 实现完整 fingerprint/current-epoch 恢复授权、候选查看/删除接口；取消单终态、磁盘失败停止新增请求。未知 source 只保留候选，不正式写入。
4. 给旧 runtime 一个通向同 owner 的兼容 facade；未迁入口覆盖/缺口显式登记，S06 才逐族移走 renderer 的终态/恢复裁决。
