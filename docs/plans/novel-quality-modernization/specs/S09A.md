## 实施步骤

1. newCharacterCandidates/规划提取输出 proposal；已有角色只用唯一 ID resolver 匹配，歧义不 first-match。
2. 明确生成角色卡的预览→批量采用携带作者 action/来源收据；静默 directory sync 不等同授权。
3. 批准 effect、ID创建/关系重映射同一领域事务，重试/恢复不重复创建；取消或冲突只保留 proposals。
4. 同步进度只能表示提议/批准结果，不能“已同步”掩盖待确认；向 S09C 提供现有 UI 可消费状态。
