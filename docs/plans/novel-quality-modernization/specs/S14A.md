# S14A — 确定性生产入口集成与代码审查证据

执行模型：Sol/high。状态：NOT STARTED；依赖满足后可派发。
Blocked by: S13。开工填写依赖实际 SHA。

必读：[通用执行合同](../05-SOL-EXECUTION.md)、[约束性契约](../03-CONTRACTS-AND-GATES.md)（全部C01–C09；代码/产品/资格分报）、[执行矩阵](../04-EXECUTION-MATRIX.md)。

## 目标与非目标

对集成最新SHA做确定性与生产入口回归和独立代码审查，提供可冻结候选；不代替真实文学测试或安装升级。 DSH、真实小说改写与正式发布不在本片。

## 文件所有权

冻结前：`test/fixtures/novel-quality-modernization/`集成案例/runner验证；S00质量工具、S04迁移工具、S13/release适配缺口交原owner与主集成者在冻结前合入。冻结后：仅隔离构建/private证据。生产修复退回对应片，不能本片无限接Bug；S14B/C/D不得修改跟踪源码。

你不是唯一开发者；不改其他片/共享区，不回滚他人改动，不再开子代理。共享接线只交一个明确请求给主集成者。

## 实施步骤

1. 确认S00–S13与三个early gate；先补齐并合入所有tracked runner/protocol/smoke/workflow适配，再进入最终验证。每个适配仍由原owner承担，不让测试引用旧worktree/错误ABI。
2. 对待冻结提交跑相关单测/浏览器/renderer入口与全量回归；独立review有阻断交回原片。任何改动重新开始此步，不先冻结再修工具。
3. 串UI→IPC→main→repository，覆盖全部生产入口；交付对称candidate execution target（代码/构建/driver SHA、ABI/启动命令、独立根）。与S00可运行baseline做零模型dry-run：实际目标不同且入口可达、数据隔离、旧新语义fixture parity成立。
4. 上述完成才冻结唯一subjectSha及artifact hash，交B/C/D只读执行。报告提交SHA与被测subjectSha分开。B/C/D任一tracked修改使当前候选及其证据失效，回原owner和本片；新SHA的质量/升级/资格不得自动继承旧PASS。

## 验收与测试

deterministic故障矩阵合并检查：预算不能逃、候选不丢/不污染、无重复角色/批次、旧租约拒写、原文/备份hash不变、no-op不假绿、unknown不伪complete。

先通过 S00 ABI/environment profile；以下为实施时执行，本轮未运行：

```powershell
pnpm run typecheck
pnpm run check:i18n
pnpm test
pnpm run test:browser
pnpm run test:renderer-surface:e2e
pnpm run build
```

## 失败、回退与交付

命令须S00隔离ABI；任何no-tests/崩溃不能计通过。生产修复后废止旧SHA资格，记录重测差异而非删除失败。

必交：同subjectSha测试矩阵与独立code-review、candidate execution target/双目标dry-run/parity receipt、冻结构建；不提交/发布。报告SHA单列；附实际命令/退出码及failed/blocked/not-run，代码、模型、安装资格分别报告。
