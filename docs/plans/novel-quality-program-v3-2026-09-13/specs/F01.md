# F01 — 经典/写手分层与偏好兼容

依赖S01；S03必须等本片。独占拟src/shared/appearance-profile.ts、renderer appearance bootstrap、theme-store/ui-version-store的hydration/单writer适配及专属storage测试。main config/skin迁移归S03，启动/IPC/App接线归主集成者；不改生成/角色等业务store。

目标：复用已有外壳开关，建立有边界的用户概念而非皮肤插件系统。

- 固定shell classic/writer与colorTheme、backgroundSkin、fonts各自语义；existing SkinId=classic仍表示无背景图，UI叫“纯色/无背景图”避免双经典。
- 旧ui-version v1/v2映射classic/writer；未知值保留并fallback Classic提示；无旧外壳值只记录unset。开发阶段安全默认暂为Classic，正式交付必须Writer默认；F05.Preflight准入后由主集成者激活Writer，再做Final/post-UI三门。不得把已有颜色/字体默认值识别成“非主动所以可改”，也不得将默认物化成作者显式选择。
- 迁移保持字段字节/相同显示含义，一次迁移不得后续反复覆盖；donor fontDefaultsVersion只能当来源信息，不再次強制重置字体。
- 壳切换只改变外观，不变project/session/model/预算/prompt。持久偏好加载未完成时不写默认覆盖；损坏偏好不扩展到模型/项目重置。
- 固定本包C10键映射：renderer的ai-novel-writer-theme和ai-novel-writer-ui-version一次迁入ai-novel-writer-appearance单JSON，由本片一个writer写；旧theme/ui-version store只投影不再各自persist。main skin保持SkinService唯一源；只读AppearanceSnapshot用profileRevision+skinRevision，不能重复持久化skin或伪造跨进程原子提交。
- mainReady后、App业务hydration/initTheme前做pending→migrated/blocked；先读旧键和main skin快照，单次setItem后read-back ack。未ack不删旧键，重启幂等；成功后不自动回灌旧键。损坏/storage不可用/main skin失败保留原值、安全Classic提示、不写默认；不得绕过C08全局门。S03维持原userData/partition/file-origin直到ack，不负责假迁renderer数据。给集成者启动/IPC单一接线请求，给S03 mainReady/ack合同，给F02纯props/data属性。

拟新增测试：src/shared/__tests__/appearance-profile.test.ts、src/stores/__tests__/appearance-bootstrap.browser.tsx。前者覆盖无键/v1/v2/未知/同值显式字体/旧classic图片与Classic壳；后者必须用实际localStorage hydration，覆盖损坏JSON、storage不可用、main skin已就绪/失败、首次写前后崩溃/ack幂等、旧键写者退出、默认激活前后unset行为。执行vitest/browser+typecheck；S03另测main持久化，不把纯parser算整个迁移完成。

回退：切壳不降库；无已确认新偏好时保留旧快照，非法外观值不影响作者数据。完成记录迁移映射与实际测试收据。
