## 用户最新边界

1. **角色头像必须保留、修好、可用**。之前未删除生产头像；v2未纳入的是“正文TXT/Markdown附带头像”，不是头像功能。本版将头像全部操作、迁移及项目备份恢复纳入明确必需项。
2. **写手是完整默认主入口**，必须实现“最新生产旧功能 ∪ 贡献者实际新增功能 ∪ 本轮批准增强”。缺按钮/接口/交互就补齐，有缺陷就修；不能隐藏、disabled、删除能力或要求切经典来通过验收。
3. **Issue要实质解决**：修复真实Bug、完成可行增强，达到原问题全部验收条件后关闭；不开空壳后继来换取旧单关闭，不把无回复当已解决。
4. 保留经典兼容、作者数据与明确偏好；不重做第二业务内核，不运行DSH或英文产品场景。
5. 本轮仍是整合计划/Spec与独立审计，不修改生产代码、真实小说、已安装应用或GitHub状态。
