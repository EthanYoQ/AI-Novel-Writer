## 实际变化

- Agent 对话、工具动作与工具派生工作流共用主进程持久运行和根预算。模型完整停止后才解释工具协议；中断、length、未知发送保留可见文字，不能执行半截工具。工具确认、实际领域写入、子工作流登记与历史回执分别校验；重复领取不重复执行。
- 导入按原 import run、阶段与章节批次查找原生成运行，主进程读取实际材料、配置与模板。新请求必须持有当前导入执行权限；已发送 ordinal 只回读原请求和结果。prepared/committed 效果封存生成；正式效果要求原阶段的完整、未丢弃候选。全局效果历史回执与当前项目事实分开读取，作者后续修改不会被旧回执覆盖。
- 编辑器 AI 操作冻结未保存文稿、UTF-16 选区、动作、实际模板与原模型。每个原动作只有一个主进程构造的请求，通用接口不能替换任务或添加子运行。跨重开保留初始身份，回复丢失仍能读取原结果和取消；原结果的读取不依赖当前模型配置存在。接受前再次核对候选资格，并在异步等待后检查当前文稿、选区、文件、会话与只读状态，只修改本地编辑内容。
- AI 输出面板显示持久助手任务与编辑器建议；未知或来源冲突保留复制入口。恢复使用明确原身份。原编辑器文稿没有规范资源身份时，以原文稿快照呈现，不自动覆盖其他文稿。
- 提示词渲染函数抽为纯模块，原 renderer 导出不变；主进程使用相同的作者指导、必须保留的上下文和内置输出约束。
