# S09B 定稿、连续性与导入角色身份接入

日期：2026-09-13。依赖 S06B/S09A `88c80aa57ad4de266c57ccd88bab961e567920d3` 与 S08 `ee4111e0927593956e3ff59b60ef07a07402a199`。本片实现和交叉审查使用 Astra/Xhigh，遵循用户指定的最低 Terra/Xhigh 调度规则。这里的合成验证不代表真实模型或发布资格。

## 写入行为

- 定稿原事务同时冻结角色 ID、当时显示名、有效别名和身份版本，与原 immutable outbox 一起提交；已有 outbox 重试不会按当前名称补造旧身份凭据。
- 默认定稿后处理先处理章节要点，再在同一主进程预算中进入角色状态生成。主进程签发上下文凭据，绑定原定稿正文与每个动态字段的值、版本和来源。正式提交只接受实际已落盘、完整结束的生成结果引用，并重新解析原始结果。
- 状态按稳定 ID 更新。模型输出只能产生 derived 来源；作者字段和非空 legacy 字段保留原值，推断进入候选。来源或字段发生变化时拒绝提交，原正文和生成结果保留。字段保存失败在同次执行中重放原提交请求；格式错误的结果不会作为可提交缓存。
- 动态状态更新只刷新角色状态的校验信息，不重写作者的静态角色 Markdown。重复提交不增加同一字段更新；提案保存失败会回滚同事务中已写入的动态字段。
- 引文可仅返回原文字符串，主进程只在原文中唯一精确匹配时计算 UTF-16 位置；显式位置严格校验。空引文、重复引文和错误位置不能猜测修正。引文校验只能证明来源位置，不能证明模型推断的语义正确性。

## 名字关联的出口

| 输入或存量数据 | 结果 |
| --- | --- |
| 定稿冻结身份，后来改名或交换显示名 | 历史 ID 与当时显示快照保留；动态写入按 ID，不覆盖当前显示名 |
| 冻结时已有同名人物，即使模型给出其中一个 ID | 保留歧义及候选 ID，等待明确确认；已证明的冻结显示名可供展示 |
| 模型只有名字，或给出未知 ID | 保留原始 occurrence、引文和来源；有显示名的条目进入现有角色提案入口；未知 ID 无名字时不编造名字，保留在生成结果和未解决项中 |
| 明确把历史名字条目关联到现有 ID | 关联身份，不用历史显示名重命名作者当前角色，不顺带采用其动态推断 |
| 旧 summary 缺少角色身份凭据或仍只有名字 | 标为 legacy；错误绑定标为 stale；仅可定位并回读定稿原文，不升级为作者事实 |
| 地点或物品标签，没有角色引用 | 保留可读标签；只有通过来源核验的 characterRefs 才构成角色关联 |
| 导入两个同名人物或同名关系目标 | 保留两个独立提取项和原始关系标签，不按名字去重或误判为同一人 |
| 未证明模型来源的旧导入提案 | 继续可读，正式采用仍拒绝；S06D 接续来源凭据和恢复接线 |
