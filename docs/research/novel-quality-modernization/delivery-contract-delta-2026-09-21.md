## 章节材料与生成行为澄清（2026-09-30）

本节依据实际消费者核对此前实现与测试的取舍，在用户授权下明确合理的产品行为；不追改冻结原 Spec、样本或历史裁决，也不证明真实模型资格通过。

- **直接前驱与容量**：写稿时，直接前章的有界定稿原文结尾是必需衔接材料，其余历史定位窗口按相关性选择。整块装不下时，可改为同一来源的结尾块，并在提示词及材料收据中记录其余窗口的省略；结尾也装不下必须停止。作者明确的必需约束不能因此变成可选项，结尾入选也不代表全部前章事实均已覆盖。
- **写稿、审稿与修稿的共享证据**：三者保持来源、版本、hash、候选准入、事实优先级和容量裁决可复算，不要求不同任务使用相同提示词字节或摘录集合。审稿的完整直接前驱和修稿的作者确认清单仍分别是必需材料。
- **时间默认**：无明确跨日或时间间隔的直接承接章节默认同日衔接；作者明确时点与间隔优先，既成事件按定稿来源换算。该规则是生成指导，不是新增作者事实，也不是新的评分 oracle；实验仍按冻结材料判断时间。
- **角色地点**：定稿派生的 `location` 只记录正文明确支持的当前位置变化，计划、决定或意图不视为位移。未返回字段不更新，作者值保护、来源和提交时 CAS 不变。
- **生成前对账（2026-09-30 前向收窄）**：新 run 直接以作者要求、已纳入的定稿和本章蓝图生成正文，不再默认调用或注入自动对账。对账本是派生建议，不能替代作者约束或定稿；实际反例显示它会把历史结果误当本章新事件，故移除这层重复规划。旧 run 恢复仍识别已记录的对账、原 hash 与预算，不把它作为正文候选或正式角色事实；取消仍停止。实验操作登记同步取消四次必发对账，真实语义 oracle 与历史 FAIL 不变。
- **计划与禁令**：人物计划可以由正文中的新决定、理由和连续性依据推进或替换，不能追溯写成早已执行。人物改口不能豁免作者明确禁令、必需呈现或既成事实；C16–C18 的具体 oracle 仍以各次冻结协议为准。
- **结构化完整性与实验接线**：超长蓝图字段不能靠机械截断后直接正式提交，须走原预算内的完整重建，失败不提交该项。蓝图 `compact-single` 重建的作者架构、入选前章蓝图字段与系统指令也不得机械截去尾部事实；目录命令对注入写作 Skill 后的完整请求执行已有结构化规划的 32,768 UTF-8 字节校验，main 仍独立执行实际模型上下文预检，装不下则请求不发送且原蓝图不变。此前仅证明裁剪后低于 16,384 字节的测试不构成语义通过证据。正文正常结束但过短也会触发产品有界续写；最终实验必须登记并核验实际生产分支的来源、组合、预算与逐物理请求，不能用历史均为 `stop` 的结果推断续写不可达。候选独有压缩能力与参考臂的不对称继续单独披露，不降低篇幅或文学质量标准。
