The main-only service mints root/run/attempt/reservation/artifact IDs. SQLite transactions retain root nonce and child open nonce mappings, immutable root caps, one invocation nonce/requestHash mapping, dispatch marks, terminal accounting and one full visible snapshot per attempt. Provider requests remain opaque: the service never serializes or hashes them. The explicit semantic requestHash is constructed by trusted main. Source manifests and usage policies must likewise be main-built, non-secret records.

M01 is 1→2, owner S05. `M01_GENERATION_SQL` creates only generation_roots, generation_runs, generation_attempts and generation_artifacts. `createM01Migration` requires the central read-only schema verifier. It does not register itself, execute later steps, or add DDL to repository getters. Existing recovery candidate and formal author tables are untouched. Final schema admission and portable-field registration remain central responsibilities.

Each repository captures one admitted SQLite handle at construction. Closing that handle makes subsequent calls fail; they cannot follow the global current-project handle into another project. Main must pause/cancel before closing its captured DB. The sole dispatch dependency executes only after committed reservation and dispatch mark. A failed mark issues zero physical requests. Repeated invocation returns the original receipt, including unknown after restart, without replaying the stream. Cancellation before dispatch releases the reservation; after dispatch it remains unknown unless a valid observed usage settlement already committed.

Usage components remain nullable at the provider seam. Known trustworthy component semantics and consistent totals are required before replacing reservation liability. Included reasoning is not added twice; separately billed reasoning included in a provider total is counted once. Missing/negative/inconsistent/unknown usage retains reservation. Usage exceeding the reservation is recorded in full and blocks later dispatch. Estimator version, safety margin and accounting policy are stored with the reservation.

Elapsed accounting measures the union of dispatch-active wall-clock intervals for one root, not local planning gaps. Pause stops the clock; restart recovery conservatively includes wall-clock time until interrupted work is recovered. An active timeout aborts and settles unknown even when a provider ignores cancellation; late success cannot revive a cancelled or timed-out attempt. All child requests share the parent root caps. This dispatch-active interpretation was confirmed by the main integrator; it is not an assertion that local planning time is metered.

Visible-only adapter deltas and cumulative prefixes become monotonic full snapshots. Trusted event IDs provide exact duplicate detection; plain duplicate text is never guessed away. One-second, 4 KiB and terminal flushes execute on the same owner; synchronous SQLite transactions serialize revisions. Saved status comes from committed artifact revision. Rollback/non-prefix updates, altered hashes, stale epochs and late terminal events are refused. Storage failure aborts, blocks subsequent dispatch and emits/returns the copyable unsaved tail. There is no claim of hardware power-loss zero loss. Partial structured text is candidate data only; no formal table write or hidden reasoning persistence is performed.

Recovery requires matching full frozen fingerprint, context identity and source manifest, then an injected trusted-main source validator. The default is refusal. Epoch change alone grants no authority. Old candidates remain readable and integrity-checked; discarded candidates are hidden from the candidate list. No S06 legacy producer is claimed migrated by this module.
