## 设计理念

这是一个写小说的工具。界面应该像一本排版讲究的书，而不是控制台：

- **正文是主角。** 正文以纸面呈现，衬线字体，每行约 34 字，两端留白。其余界面都退后。
- **墨与纸，加一种颜色。** 界面几乎只有墨色与纸色。黛蓝是唯一的强调色，只标记三件事：主操作、当前位置、键盘焦点。
- **顺序可见。** 流程脊自上而下的排列就是真实的创作顺序，状态标记（完成、进度环、未开始）说明每一步走到哪里。
- **克制的动效。** 只在状态变化时动：侧页滑入、弹层浮现、进度推进。没有循环装饰动画。

## 令牌

令牌的实现在 `src/styles/paper-ink/tokens.css`，挂在 `.paper-ink` 作用域上，是渲染进程里唯一允许写颜色值的文件。组件只引用令牌。`prototype/tokens.css` 是原型用的旧命名，以实现为准。

| 类别 | 令牌 | 用途 |
|---|---|---|
| 表面 | `--frame` `--sunken` `--surface` `--surface-2` `--paper` | 应用底、凹陷输入、面板、悬停与选中、正文纸面 |
| 墨色 | `--ink` `--ink-2` `--ink-3` `--ink-4` | 正文与标题、次要文字、说明、禁用与占位 |
| 线 | `--rule` `--rule-strong` `--track` | 分隔线、控件边框、进度轨道（如章节生命周期的未开始段） |
| 强调 | `--accent` `--accent-hover` `--accent-ink` `--accent-soft` `--accent-line` | 主操作、当前位置、焦点 |
| 语义 | `--danger` `--ok` `--warn` 及各自 `-soft` | 危险、完成、提醒。与强调色色相不同 |
| 字体 | `--font-ui` `--font-display` `--font-prose` `--font-num` `--font-mono` | 界面无衬线、标题衬线、正文衬线、旧式数字、诊断等宽 |
| 字号 | `--fs-11` 至 `--fs-36`，正文 `--prose-size` 18px / 行高 2.05 | 9 级阶梯 |
| 间距 | `--s-1` 至 `--s-16` | 4px 的倍数 |
| 圆角 | `--radius-sm` 4、`--radius` 6、`--radius-lg` 10、`--radius-pill` | |
| 动效 | `--ease`、`--dur-fast` 140ms、`--dur` 220ms | 只用于状态变化 |

浅色与深色两套主题共用同一组令牌名，深色只改值。不再有皮肤和背景图。

## 组件

每种组件只有一个实现。原型 `prototype/ui.css` 中的类名即组件清单：

- 按钮：主按钮、次按钮、幽灵按钮、危险描边按钮、危险实心按钮（只在危险确认里）、图标按钮；三种尺寸。
- 表单：输入框、下拉、多行文本、复选、单选、开关、分段切换、展开项。
- 容器：卡片、列表、侧页（含分页）、对话框、弹层、菜单、选区工具条、提示条。
- 状态：徽标、状态点、进度条、进度环、章节生命周期、空状态、危险区。
- 外壳：顶栏、流程脊、章节列表、作品资料导航、标签条、运行胶囊、宽版侧页。
- 原型里各屏自建、实施时要统一成共用组件的：统计格（`.summary`/`.stats`）、提示条（`.resume`/`.recover`/`.nudge`/`.proposals`）、设置页骨架与设置行、单选卡片、勾选列表、就地确认条、运行任务卡与步骤、定稿后处理步骤、逐段合并块、日志、剧情时间轴、线索路线、候选卡、书卡与入口卡、人物标签与头像、编号分节卡。

## 规则与验收标准

“获奖品质”无法直接审查，下面每一条都可以由审查者逐项核对。

**结构**

1. 主导航只有四个创作阶段，按创作顺序自上而下排列，每项显示状态。
2. 每个功能只有一个规范入口（对照 `feature-matrix.md` 的落位表）。
3. 每个交互层只有一个主按钮，它是流程上的下一步。对话框是独立的交互层；拆分主按钮（主按钮加下拉箭头）算一个。没有流程下一步的页面（诊断、外观设置）可以没有主按钮。
4. 写作此章不再弹出重复蓝图字段的表单。

**视觉**

5. 一个视觉概念，没有装饰性叠加层：没有水印数字、彩带、分区色条。
6. `src/components` 中没有十六进制、rgb、hsl 颜色字面量；只有一层颜色令牌。
7. 强调色与危险色、提醒色、完成色色相不同。
8. 危险操作与主操作外形不同（描边红字或实心红色，从不使用强调色）。
9. 浅色与深色下，正文与背景对比度不低于 WCAG AA（4.5:1），说明文字不低于 3:1。
10. 只有一个按钮组件；不出现原生 `<button>` 直接带样式。

**交互**

11. 所有危险操作都有确认，并写明后果和能否恢复。不可逆且影响作品数据的操作用危险确认对话框；删除整部作品还要输入作品名。侧页内影响较小的操作（清空日志、放弃一条恢复候选）可以用就地确认条。
12. 所有空状态都经过设计：标题、说明、一个动作。
13. 所有可编辑页面都响应 ⌘S / Ctrl+S；⌘W 关闭当前标签；⌘P 查找章节。
14. 键盘可以到达每个控件，焦点环清晰可见。
15. 动效只出现在状态变化上，并尊重“减少动态效果”设置。

**语言**

16. 创作界面不出现实现术语（LanceDB、FTS、BM25、Embedding、向量、query、MCP、token）。例外：token 只用作模型设置“最大输出 Tokens”这一项的名字，以及请作者去调它的提示；其余地方（含诊断、运行侧页）不出现。
17. 同一对象全应用只有一个名字（例如“备份”只叫“项目备份”）。
18. 样式选择器不依赖元素位置、工具类名组合或本地化文字。中英文界面都通过 `pnpm check:i18n`。
