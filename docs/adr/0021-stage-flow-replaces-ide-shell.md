# 以创作阶段组织界面，取代 IDE 四区外壳

2026-10-11 提议；同日用户选定视觉方向 A「纸墨」，确认移除背景图皮肤、合并运行面板、保留多标签编辑。

状态：已接受。前端重做 RD-0 至 RD-10 按本决定实现，RD-10 起纸墨外壳是默认且唯一的界面。各 PR 的验收记录在 `docs/design/2026-10-11-frontend-redesign/plan.md`。

## 决定

渲染进程的主界面不再采用 IDE 式四区外壳（左右工具窗口栏、项目树、标签页编辑区、右侧助手、底部面板与状态栏）。作品内的主导航改为按创作顺序排列的四个阶段：设定、架构、蓝图、正文。每个功能只有一个规范入口；工作流运行、审稿与修稿、版本对比、资料速查都以按需出现的侧页或浮层呈现。具体结构见 `docs/design/2026-10-11-frontend-redesign/ia.md`。

视觉层只保留一层颜色令牌和一套组件原语。样式不得依赖元素位置（`nth-child`）、Tailwind 工具类名或本地化文本来选中元素。

## 原因

1.2.2-Preview 的审核（UX-01～UX-26）显示，导航顺序混乱、同一功能多入口、视觉语言冲突，根源都在外壳本身。之前两次改版只在同一外壳上换皮，这些问题一个都没有消除。

## 后果

- `LeftToolWindowBar`、`RightToolWindowBar`、`BottomToolWindowBar`、`ShellV2`、`v3-magazine.css`、`writer-shell.css` 及其相关测试已移除，外观设置里不再有界面布局一项。
- AI 输出、任务面板和状态栏进度合并为一个“运行”侧页。原有显示内容全部保留。
- 主题与皮肤收敛为浅色和深色两套，动漫背景与自定义背景图皮肤及其进程间通道已移除。外观配置换用新键：旧配置的 galaxy 迁为深色，paper 与 light 迁为浅色，图片皮肤迁为无皮肤；旧键原样保留、只读不写，回退到旧版本时仍可读。
- 内容区保留多标签编辑，标签条只在打开多个页面时出现。
- 沿用的旧组件（提示词模板、写作 Skills、项目备份、模型表单、导入导出对话框等）放在纸墨页面里，旧颜色变量由纸墨令牌接管，随浅色、深色换色。
- 本决定不改变 ADR-0008：聊天界面隐藏，代码与 seam 保留。工作流、领域提交和项目会话的边界保持不变，重新设计只替换呈现层。
