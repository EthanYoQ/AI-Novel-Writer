# 旧小说项目以完整副本导入新版

2026-09-24 用户接受完整副本导入；2026-09-25 用户批准采用普通离线导入，取代跨存储原子快照前置要求。本文决定产品行为，不声明实现或验收已通过。

## 决定

旧小说项目通过显式「导入旧项目」转换为独立的新项目。源目录保留，新项目位于不相交的新目录，使用新的 projectId/会话身份。不在源目录内原地转换、写迁移标记、改权限、搬走源文件或退役旧根；不再承诺永久阻止旧程序写入原根。用户被告知两份项目此后独立，旧版后续修改不会自动同步到新版，重复导入不能覆盖已存在的新项目。

这是项目格式兼容，不是导入一篇小说后重新拆解。完整保留源项目已存的前提、题材/创作配置、大纲、蓝图、世界观、角色原始资料与关系、章节正文、草稿/版本、审修/定稿记录、叙事线索、头像、知识库原文及既有项目级 prompt/Skill 等数据；精确类别继续服从既有资产清单。新身份不能打断内部领域 ID 与引用。来源未知的 legacy 数据保持原文和来源状态，不因导入升格为作者已确认事实。

**转换不调用 AI，不根据正文重建或覆盖作者设定，也不自动触发生成、审稿、角色提取、摘要重写或旧任务重放。** 新版必须能按保留下来的作者事实继续写作，不能仅复制一批不可用的文件就宣称完整导入。旧原始角色资料若不能确定性映射为新版结构，应原样保留在源及受控 staging、显示待兼容的数据项，不作为成功项目加入书架或开放写作；不得让 AI 猜测填充或声称已完整可用。

源已有的派生资料保留其来源；索引仅在不改作者事实且无模型调用时可确定性重建，无法兼容的向量空间标明不可用，不能悄悄付费重新生成。缺失/损坏/无法映射的必需资料不能静默跳过或靠 AI 补齐；返回具体缺口且不发布半成品为成功项目。凭据、机器绝对路径、外部文件授权和旧执行权限继续服从既有安全/portable 边界：不复制成新授权，必要时提示重新配置；这些不属于允许丢弃创作资料的例外。

## 一致性与恢复

支持普通离线完整导入：提示用户保存并关闭旧版及该项目的同步/编辑程序，导入期间不要重新打开或修改源；将完整项目复制到不相交目标的 staging，只在副本转换和恢复。导入器不修改源 SQLite/WAL/journal、资料文件、权限或标记；不能遗漏仍承载已保存数据的 WAL。复用已有复制、数据库恢复与资产清单校验，核对复制前后源清单/内容变化、目标数据库完整性、领域引用及必需资料/资产；发现变化、缺失、损坏或不支持格式就停止，不发布半成品。

此路径以用户遵守离线操作前提为支持边界，不承诺在其他程序并发修改源时仍得到跨存储同一时点的原子快照。关闭提示、进程检查、前后哈希属于操作与变化检测，不能称为原子性证明，也不要求证明没有任何外部写入者。停止把 VSS、管理员权限、虚拟磁盘、目录持续排他或防同账户恶意竞态作为本路径的前置门；无需保持转换后源目录的长期排他。该取舍不降低完整资料保全、目标验证、源不写入和失败恢复要求；旧严格快照实验的失败仍按原合同保留，不追溯改判。

只有目标完整校验成功才发布为新项目并加入书架；失败/取消/中断只影响本次目标 staging，可清理或按现有机制恢复。既有新项目和源不受损。新项目打开、编辑、保存和重开不会回写旧项目；旧版继续保存旧项目也不会改变新项目。源转移的候选/outbox/运行记录仅作为不可自动重放的可读历史；引用和 lineage 重绑复用 ADR 0018 的 C17 边界。

## 取代范围

取代冻结 S04/S14C 及旧 F05/U10.A11 中的原地切换、旧根退役、迁移后旧版原根必须拒写及其长时排他要求；原 A11 的数据保全能力仍须通过 V3 实际入口验收。[现行规格](../research/novel-quality-modernization/frontend-transition-specs.md)拥有本轮执行与证据出口。

对 [ADR 0018](0018-program-v3-domain-contracts.md) 的 project-storage 仅部分取代：本路径的 journal/staging 在新目标所属范围，源不写 journal、不移动 `.vela`；registry、真实路径授权、来源验证、C17 可读权限转移及故障恢复要求继续有效。应用全局配置迁移、安装更新、同一新版项目的会话保护不在替代范围。冻结文件和历史失败不改写，旧原地迁移不得继续作为自动打开旧项目的回退路径。
