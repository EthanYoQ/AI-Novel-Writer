# 定稿章节删除采用事实提交与可恢复投影清理

SQLite 中的已定稿章节、不可变正文和定稿收据是事实源；删除命令必须绑定当前项目会话，在同一事务中先冻结草稿 ID、章节号、定稿 ID、实体稿目标、知识文档 ID 与后处理记录 ID 并登记删除操作，再删除章节事实和后处理记录。实体稿文件和知识库文档及切片是事务外的可恢复投影，每项清理都持久化完成或失败状态与准确原因，重复请求必须匹配完整冻结身份，应用重启后继续重试同一操作。旧定稿若没有可靠的知识文档来源身份，也没有明确的“不需要知识投影”后处理证据，系统先登记 `authorization_required` 收据并保留全部事实与投影；只有用户在双语危险确认中声明已人工核对或清理、且没有需要应用自动删除的知识投影，才能把该收据上的一次性授权原子记录为已消费并继续事实删除，应用仍不猜测或删除任何来源不明的 reference 文档，普通知识库清理失败也不能使用此授权绕过。
