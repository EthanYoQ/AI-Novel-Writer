# Domain Docs

本仓库采用单一领域上下文。

## 探索前读取

- 根目录 `CONTEXT.md`：稳定且面向用户的项目术语。
- `docs/adr/`：难以逆转、具有真实取舍且未来读者可能无法从代码理解的架构决定。

文件不存在时可以继续工作；只有在领域术语或架构决定真正形成时，才由 `domain-modeling` 创建。

## 使用规则

- Issue、规格、测试和代码中的领域概念应优先使用 `CONTEXT.md` 定义的名称。
- `CONTEXT.md` 只保存术语及其边界，不保存实现步骤、临时计划或测试清单。
- 如果实现方案与现有 ADR 冲突，必须明确指出并先更新或取代该 ADR。
- 新 ADR 使用 `docs/adr/NNNN-slug.md` 的连续编号。
