# AI小说作家 Design System

AI小说作家是一个 AI 深度驱动的小说创作 IDE，其 UI 设计系统基于 Tailwind CSS v4 + CSS 变量实现主题化。

## Design Tokens

AI小说作家使用 CSS 自定义属性（CSS Variables）作为设计 token 的单一数据源，支持 `light`、`galaxy`、`paper` 和 `dark` 四套主题。下面的色板直接渲染运行时变量，不维护第二份颜色常量。

## Spacing Scale

| Token | Value | Usage |
|-------|-------|-------|
| `1` | 4px | Tight grouping |
| `2` | 8px | Default internal spacing |
| `3` | 12px | Component padding |
| `4` | 16px | Section padding |
| `5` | 20px | Large gaps |
| `6` | 24px | Panel padding |

## Components

AI小说作家 UI 提供 20+ 原子组件，位于 `src/components/ui/`：

- **Button** - 按钮组件，支持 6 种变体
- **Badge** - 标签组件，用于状态标识
- **Input** - 输入框组件
- **Dialog** - 对话框组件
- **Toast** - 全局通知系统
- **Tooltip** - 提示组件
- **Switch** - 开关组件
- **...**

详见各组件文档。
