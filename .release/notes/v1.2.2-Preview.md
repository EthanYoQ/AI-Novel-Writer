# 1.2.2-Preview

## 中文

- 修复从书架打开旧作品失败的问题。
- 修复迁移提示无法关闭和左侧导航点击受阻的问题。
- 生成配置时带入当前作品名，减少与示例作品混淆。
- 指导弹窗支持滚动查看完整内容。
- 角色确认入口移至右侧，方便继续处理。
- 修复剧情树恢复时生成连接中断的问题，保存后显示结果。
- 修复批量写作时，迟到通知造成的流程未完成误报。
- 修复定稿时角色处理的重试问题。
- 清空蓝图后，可以继续生成新的蓝图。
- 一键生成小说配置会预填已有大纲，可直接编辑并生成。
- 修改审稿选择后，可以重新确认审稿清单。
- 明确标注"不修改此项"表示该项不纳入修稿。编辑清单时可以重新选入。
- 审稿项撤回"不修改"后，保留原来的"待核实"判断。
- 生成恢复信息异常时，仍可查看来源完好的历史角色建议。
- 旧项目格式不兼容或损坏时，提示原因和下一步。

这是 1.2.1-Preview 的修复版。版本名保留 Preview，使用正式发行渠道。

请从本页下载安装包。旧版无法通过应用内更新识别此 Preview 版本。

Windows 安装包未签名。Mac 安装包未获 Developer ID 签名和 Apple 公证。系统可能提示未知发布者或阻止打开。

## English

- Fixed failures when opening older works from the library.
- Fixed a migration notice that could not be closed and blocked clicks on the left navigation.
- Configuration generation now receives the current book title to reduce confusion with the example book.
- Guidance dialogs allow scrolling through their full content.
- The character confirmation entry is now on the right.
- Fixed interrupted generation connections when restoring the story tree. The app shows the result after saving.
- Fixed false reports of an unfinished workflow caused by late notifications during batch writing.
- Fixed retries for character processing during chapter finalization.
- New blueprints can be generated after clearing existing blueprints.
- One-click novel configuration generation now prefills the existing outline, which you can edit before generating.
- After changing review selections, you can confirm the review checklist again.
- "Do not revise this item" now clearly means the item is excluded from revision. You can include it again by editing the list.
- After withdrawing "Do not revise" for a review item, its original "Needs verification" judgment remains.
- If generation recovery information has errors, you can still view historical character suggestions with intact source records.
- If an older project's format is incompatible or damaged, the app explains the cause and the next step.

This is a bug-fix update to 1.2.1-Preview. The version name retains Preview and uses the regular release channel.

Download an installer from this page. Older versions cannot detect this Preview version through the in-app updater.

Windows installers are unsigned. Mac installers have no Developer ID signature or Apple notarization. Your system may show an unknown-publisher warning or block the app.
