# 1.3.2

## 中文

1.3.2 主要让报错和提示按界面语言说清楚，并修复运行侧页恢复卡片显示原始审稿输出的问题。作品数据、设置和安装位置都不变。

改进：

- 报错按界面语言显示。中文界面不再出现 `PROJECT_SESSION_STALE` 这类裸错误码，英文界面不再夹带中文原文。覆盖打开、新建和删除作品，外部文件授权，角色名单、蓝图与剧情，定稿、修订与删除章节，知识库与检索，模型连接测试与 MCP，以及导入。
- 导入参考小说或作者原稿时，取消和失败的说明按导入时的界面语言写，运行卡片、导入对话框和可继续的导入列表都一样。导入前的「预估 AI 消耗」各项按实际估算显示，不再写死数字。
- 模型设置里的连接测试失败时，说明会写出 HTTP 状态，并提示检查 Base URL、API Key 和模型名。
- 运行侧页的诊断和预算提示不再出现 token 这类技术术语。设置项统一叫「最大输出 Tokens」。

修复：

- 运行侧页「可恢复」卡片里的审稿结果不再显示模型返回的原始 JSON，改为显示审稿结论、意见条数和前两条意见。「复制」得到的仍是原文。
- 安全更新：自动更新用来读取更新信息的 YAML 解析组件升级到修复版本，修复一个可导致拒绝服务的问题。

请从本页下载 Windows x64、macOS Apple Silicon 或 macOS Intel 安装包。已安装 1.1.0、1.2.x、1.3.0 或 1.3.1 的用户会在应用内收到更新提示；macOS 上提示会打开本页，需要手动下载新的安装包。

Windows 安装包未签名。Mac 安装包使用 ad-hoc 签名，未获 Developer ID 签名和 Apple 公证。系统可能提示未知发布者或阻止打开。

## English

1.3.2 makes errors and notices explain themselves in the interface language, and stops the run sheet's recovery cards from showing raw review output. Project data, settings, and the install location are unchanged.

Improvements:

- Errors appear in the interface language. The Chinese interface no longer shows bare error codes such as `PROJECT_SESSION_STALE`, and the English interface no longer mixes in Chinese text. This covers opening, creating, and deleting projects, external file access, the cast, blueprints, and plot, finalizing, revising, and deleting chapters, the knowledge base and retrieval, model connection tests and MCP, and import.
- When you import a reference novel or your own manuscript, cancellation and failure messages use the interface language that was active when the import started. This applies to the run card, the import dialog, and the list of resumable imports. Each line of Estimated AI usage before an import now shows the actual estimate instead of a fixed number.
- When a connection test fails in model settings, the message shows the HTTP status and asks you to check the Base URL, API key, and model name.
- Diagnostics and budget notices in the run sheet no longer use technical terms such as token. The setting is consistently named Max output tokens.

Fixes:

- Review results in the run sheet's Recoverable cards no longer show the model's raw JSON. They show the review verdict, the number of comments, and the first two comments. Copy still gives you the original output.
- Security update: the YAML parser that automatic updates use to read update information is upgraded to a fixed version, which closes a denial-of-service issue.

Download a Windows x64, macOS Apple Silicon, or macOS Intel installer from this page. Users on 1.1.0, 1.2.x, 1.3.0, or 1.3.1 get an in-app update notice. On macOS, the notice opens this page, and you download the new installer manually.

Windows installers are unsigned. Mac installers are ad-hoc signed, with no Developer ID signature or Apple notarization. Your system may show an unknown-publisher warning or block the app.
